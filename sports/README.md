# 오늘의 경기

KBO·MLB·NPB와 K리그·EPL·분데스리가·리그1·MLS의 일정과 결과를 한 페이지에 모은 대시보드.
→ https://www.hds.ai.kr/sports/

- 데이터: 네이버 스포츠 (비공식 API 두 곳 — 아래 참고)
- 날씨: Open-Meteo (`api.open-meteo.com`, 키 불필요, CORS 개방)
- 지도: Leaflet 1.9.4 + CARTO 타일 (테마 따라 dark/light 교체)
- 그 외 의존성 없음. `index.html` 하나로 동작

## 화면

- 상단에 응원팀(KIA 타이거즈 / 수원 삼성) 고정. 내 점수를 먼저 적고 상대를 뒤에 둔다
- 컬럼 두 개(Baseball / Football), 각각 리그 토글
- 오른쪽 레일에 구장 지도와 경기 시각 기준 날씨. **국내 경기만** (해외 구장 좌표가 없다)
- 날짜 선택기 + `←` `→` 키
- 테마 시스템/밝게/어둡게. 선택은 `localStorage`의 `hds-sports-theme`에 저장하되 실패해도 무시
- 경기를 누르면 상세 — 이닝별 점수, 득점, 팀 기록
- 경기 중이면 60초, 아니면 5분 간격 자동 갱신

Jekyll front matter를 **일부러 넣지 않았다.** 이 파일은 `<head>`부터 갖춘 완결된 문서라,
front matter가 있으면 minimal-mistakes 레이아웃이 씌워져 HTML이 겹친다.
front matter가 없으면 Jekyll이 그대로 복사한다.

## 데이터 출처가 두 곳이다 — 여기서 가장 오래 헤맸다

| 무엇 | 어디 |
|---|---|
| 일정·결과·점수 | `/schedule/games?upperCategoryId={카테고리}&fromDate=&toDate=` |
| 이닝별 점수, 득점자 | `/schedule/games/{gameId}/record` (실패 시 `preview`, `relay`) |
| **축구 팀 기록** | `/statistics/categories/{리그코드}/games/{gameId}/teams` |

세 번째가 함정이다. 축구 팀 기록은 일정 API 어디에도 없다. **없는 곳에서 파싱을 아무리
정교하게 다듬어도 소용없다.** 안 나오는 항목이 있으면 파서를 의심하기 전에 출처부터 확인할 것.

`upperCategoryId`는 `kbaseball` / `wbaseball` / `kfootball` / `wfootball` 네 가지.
국내와 해외가 별도 카테고리라 갱신 1회당 요청이 4건이다.

통계 API의 `{gameId}`는 **일정 API가 주는 `gameId` 그대로**다. 국내는 `20260726HHLG02026`,
해외는 `K0pebGLvZ2juWhu` 같은 형태라 다른 체계처럼 보이지만 같은 값이다.

## 리그 설정 (`LEAGUES`)

토글, 리그 판정, 통계 API 코드, 좌우 보정이 전부 여기 모여 있다. 리그를 추가하거나 고칠 일은
대부분 이 객체만 건드리면 된다.

| 토글 | `code` (통계 API) | `xswap` |
|---|---|---|
| EPL | `epl` | **적용** |
| 분데스 | `bundesliga` | **적용** |
| 리그1 | `ligue1` | **적용** |
| MLS | `mls` | 없음 |

`xswap`은 홈/원정을 한 번 더 뒤집으라는 뜻이다. **원리로 도출한 값이 아니라 화면을 보고
기록한 값이다.** 왜 MLS만 다른지는 응답을 확인하지 못했다. 네이버가 바꾸면 다시 봐야 한다.

EPL 판정에는 제외 조건이 있다. `프리미어`만 보면 **스코틀랜드 프리미어십**이 딸려 온다.

## 표시 항목 (`STAT_DEF`)

네이버 각 종목 '기록' 탭과 같은 항목·같은 순서로 고정했다. `strict: true`라 목록에 없는
항목은 표시하지 않는다.

- **야구** (6) 안타, 홈런, 도루, 삼진, 병살, 실책
- **K리그** (9) 볼점유율, 슈팅, 유효슈팅, 코너킥, 오프사이드, 선수교체, 파울, 경고, 퇴장
- **해외축구** (17) 위 9개 + 패스시도, 패스성공, 키패스, 프리킥, 선방, 골킥, 기대득점, 기대도움

국내축구와 해외축구는 항목이 달라 **정의를 분리**했다. 골킥은 K리그 화면엔 없고 해외엔 있다.
한 종목으로 묶으면 한쪽을 고칠 때마다 다른 쪽이 틀어진다.

## 겪은 함정들

앞으로 비슷한 증상이 나오면 여기부터 볼 것.

**엉뚱한 표를 물어온다.** 응답 안에 `home`/`away` 짝이 여러 개 있다. 시즌 순위표
(`awayStandings` / `homeStandings`)를 경기 기록으로 착각한 적이 있다 — `era`, `rank`,
`w`, `l` 같은 값이 보이면 그거다. 지금은 후보를 전부 모은 뒤 **아는 항목이 가장 많은 표**를
고르고, 키 이름에 `standing`·`rank`·`season`·`pitcher`·`lineup`이 들어가면 후보에서 뺀다.

**이닝 배열은 0부터 시작한다.** 사람은 1회부터 센다. 배열을 숫자 키 객체로 오인해 `i=1`부터
훑는 바람에 1회를 통째로 버리고 9회가 사라진 적이 있다. **합계가 최종 점수와 맞아떨어져서
더 안 보였다.** 지금은 키를 정렬해 순서대로 담아 0부터든 1부터든 첫 칸을 흘리지 않는다.

**홈/원정이 뒤집혀 온다.** MLB·NPB는 바깥 키 이름과 실제 팀이 어긋난다. 판정 순서는
① 팀 이름 대조 → ② `bhome` 같은 홈 표시 플래그 → ③ 이미 아는 최종 스코어와 대조
→ ④ `SWAP_DEFAULT` / `xswap`. ③은 추측이 아니라 검산이라 가장 믿을 만하다.

**키 이름은 예상을 벗어난다.** 병살은 `gd`였고, 유효슈팅은 `shotsOnGoal`이었다.
`cornerKickCount`처럼 접미사가 붙기도 한다. `labelOf()`가 `Count`·`Num`·`Total` 접미사,
`team`·`match` 접두사, 복수형 `s`를 떼어가며 사전을 두드린다.

**패스성공은 이름으로 못 찾아 관계로 찾는다.** 패스시도의 50~99%인 값은 패스성공밖에 없다.
후보가 정확히 하나일 때만 이름을 붙인다.

**막대 눈금은 크기대별로 나눈다.** 행마다 따로 재면 같은 값이 행에 따라 다른 길이가 되고
(코너킥 6 vs 슈팅 6), 표 전체에 하나만 쓰면 패스시도 508 옆에서 코너킥 5가 실오라기가 된다.
`STAT_GROUP`이 `pct` / `pass` / `xg` / `count`로 묶는다.

**구장 좌표는 파일에 직접 넣었다** (`VENUES`). 종목별로 나눠뒀는데, "광주"가 야구에선
챔피언스필드, 축구에선 월드컵경기장이라 합치면 안 된다. 팀 이름 매칭도 마찬가지로
**수원 삼성과 수원FC**를 구분한다.

## `index.html`에 구글 Apps Script 주소가 박혀 있는 이유

**이건 유출이 아니다. 감출 수 없는 값이고, 감추는 대신 무력화한 것이다.**

브라우저가 네이버 API를 직접 부르면 CORS에 막힌다. 그래서 Apps Script를 중계로 둔다.
그런데 이 주소는 페이지와 함께 브라우저로 전달되므로, 저장소를 비공개로 돌리든 뭘 하든
소스 보기 한 번이면 드러난다. **클라이언트로 내려가는 값은 비밀이 될 수 없다.**

그래서 방어를 주소의 비밀성이 아니라 엔드포인트의 권한 범위에 둔다.

```javascript
var ALLOW = /^https:\/\/api-gw\.sports\.naver\.com\//;
```

이 한 줄이 없으면 이 스크립트는 아무 주소나 대신 요청해주는 공개 중계기가 되고,
그 요청은 전부 내 구글 계정 명의로 나간다. **허용 목록이 이 구조의 유일한 방어선이다.**

### 살아 있는지 확인하는 법

배포 URL 뒤에 붙여서 브라우저로 열어본다.

| 요청 | 정상 응답 |
|---|---|
| `?url=https://example.com` | `{"error":"not allowed"}` |
| `?url=https://api-gw.sports.naver.com/schedule/games?...` | JSON 데이터 |

첫 줄에서 example.com 내용이 나오면 방어가 뚫린 것이다. 대개 코드는 고쳤는데 새 버전을
배포하지 않은 경우다 — [배포 관리] → 편집 → 버전 **새 버전** → 배포.
("새 배포"를 만들면 URL이 바뀌어 `index.html`도 고쳐야 한다.)

### 하면 안 되는 것

- 저장소를 비공개로 돌리기 — 노출은 그대로고, 무료 플랜이면 Pages가 내려간다
- Apps Script를 허용 목록 없이 재배포하기
- 허용 목록을 넓히기 (다른 API가 필요하면 패턴을 추가하되, 와일드카드는 금물)

## 알아둘 것

- Apps Script 무료 한도는 하루 2만 건. 이 페이지는 갱신 1회당 4건(카테고리 4개)이고,
  탭을 열어두면 경기 중 1분·평소 5분 간격으로 돈다. 공개 페이지라 방문자가 늘면 다시 볼 것
- 8월 중순 전에는 EPL·분데스·리그1이 휴식기라 "경기 없음"이 정상이다
- 토글에 안 걸린 리그가 있으면 컬럼 아래에 리그명이 그대로 뜬다. 반대로 **각 토글이 실제로
  물어온 리그 이름**을 목록 위에 적어, 잘못 잡은 것도 눈에 보이게 했다
- `strict: true` 때문에 목록에 없는 항목은 조용히 빠진다. 뭔가 안 보이면 상세 모달의
  **원본 데이터 보기**에서 실제 키 이름을 확인할 것. 값으로 검색하면 빠르다
- 진단용 장치(후보 표 선택, 좌우 출처 표시, 경기 ID 노출)는 정리 단계에서 걷어냈다.
  다시 막히면 되살릴 만하다
