안녕하세요, 헬로데이터사이언스 나성호입니다.

지난 5회차에서 좋은 프롬프트의 9가지 요소를 알려드리면서, 이걸 한 번에 완벽하게 담기는 쉽지 않다고 말씀드렸죠. 오늘은 그 현실적인 해법을 알려드리겠습니다. 결론부터 말하면, **처음부터 완벽하게 쓰려 하지 말고, 짧게 시작해서 대화로 다듬어가시면 됩니다.**

## 조건이 부족하면 무슨 일이 벌어질까

먼저 실제 사례를 하나 보여드리겠습니다. 강의 자료에는 같은 계정, 같은 모델로 "제주도 3박 4일 여행 계획을 짜줘"라는 조건이 부족한 프롬프트를 두 번 실행한 화면이 있었습니다. 한 번은 일반 대화창에서, 한 번은 '새 채팅'으로 시작한 임시 대화창에서요.

결과는 놀랍게도 서로 달랐습니다. 같은 계정과 모델을 썼는데도, 누락된 조건을 AI가 각자 다르게 추정해서 일정표의 제목과 출력 형식이 완전히 달라진 겁니다. 조건이 부족한 프롬프트는 모델이 누락된 정보를 임의로 추정해서 답하기 때문에, 실행할 때마다 결과가 달라질 수 있다는 걸 보여주는 사례입니다.

반대로 조건을 명확하게 지정하면 어떨까요? 도착 시각, 숙소 위치, 선호하는 여행 스타일, 원하는 출력 형식까지 지정한 프롬프트로 실행하면, 사용자가 요구한 기준과 형식에 딱 맞춰 답변이 나옵니다. 심지어 서로 다른 대화창에서 실행해도 제목과 내용이 상당히 유사하게 작성됩니다.

## 좋은 프롬프트는 훈련으로 만들어집니다

좋은 프롬프트는 문장을 길게 쓰는 능력에서 나오는 게 아닙니다. **사용자가 원하는 결과를 분명히 정하고, 그 결과를 얻기 위한 조건을 빠뜨리지 않는 능력**에서 나옵니다. 강의 자료가 제시하는 다섯 가지 핵심 질문으로 훈련해보시길 권합니다.

|<center>구분</center>|<center>핵심 질문</center>|<center>예시</center>|
|---|---|---|
| 문제 정의 | 내가 얻고 싶은 결과는 무엇인가? | 최근 3개월 동안 이탈률이 높아진 고객군을 찾고 싶어 |
| 단계 분해 | 어떤 순서로 처리해야 하는가? | 데이터 확인 → 결측값 확인 → 월별 이탈률 계산 → 연령대별 비교 순서로 진행해줘 |
| 조건 명시 | 반드시 지켜야 할 기준은 무엇인가? | 이탈률은 이탈 고객 수를 월초 활성 고객 수로 계산해 |
| 예시 작성 | 원하는 결과물은 어떤 모습인가? | 표의 열 이름, 그래프 제목을 정해줄게 |
| 검토·수정 | 현재 답변에서 무엇이 부족한가? | 작성해준 코드를 실행했더니 에러가 발생했어. 에러 메시지를 알려줄테니 해당 코드를 수정해줘 |

## 긴 프롬프트, 직접 다 쓰지 않아도 됩니다

9가지 요소를 다 채운 긴 프롬프트를 매번 손으로 쓰는 건 사실 번거롭습니다. 이럴 때 쓸 수 있는 네 가지 방법이 있습니다.

|<center>방법</center>|<center>내용</center>|<center>참고</center>|
|---|---|---|
| 생성형 AI에게 초안 맡기기 | 하고 싶은 작업을 짧게 설명하고, 프롬프트 초안 작성을 요청 | 가장 빠르지만, 초안을 그대로 쓰지 말고 업무 기준에 맞게 수정해야 함 |
| 이전 대화를 정리시키기 | 짧은 요청으로 시작해 대화가 어느 정도 진행되면, 합의된 내용을 프롬프트로 정리해달라고 요청 | 실제 업무에서는 이 방법이 가장 자연스러움 |
| 공개된 예시 참고하기 | 공개된 프롬프트 예시를 가져와 내 상황에 맞게 수정 | 공개된 프롬프트에는 내 의도와 안 맞는 조건이 섞여 있을 수 있음 (참고: [prompts.chat](https://prompts.chat)) |
| 템플릿 채우기 | 정해진 템플릿의 골격에 내 상황을 끼워 넣은 뒤 요청 | 반복 업무에는 템플릿 방식이 가장 안정적 |

## 핵심은 "단계별 요청"입니다

좋은 프롬프트의 구성 요소를 다 알고 있어도, 실제 데이터 분석에서 이 요소를 처음부터 빠짐없이 한 번에 담아 완벽한 프롬프트를 쓰기는 어렵습니다. 무엇이 모호했는지는 결과를 직접 보기 전까지 알기 어렵기 때문입니다.

그래서 처음부터 완벽한 프롬프트를 길게 쓰려는 것보다, 생성형 AI와 대화하며 프롬프트를 단계적으로 다듬는 편이 더 빠르고 정확합니다. 첫 요청은 짧아도 됩니다. 결과를 보고 부족한 부분을 발견하면, 그에 해당하는 요소를 다음 지시에 더하면 됩니다. 이게 바로 분석 작업을 여러 단위로 나누고 중간 결과를 검토하기 위한 실무 전략, **단계별 요청**입니다.

## 실습 데이터로 직접 해볼까요

여기서부터는 실습입니다. `customer_churn.csv`라는 더미 고객 이탈 데이터로 단계별 요청을 직접 연습해보겠습니다. 기준월 월초에 이미 가입되어 있고 아직 이탈하지 않은 고객을 월초 활성 고객으로, 기준월 안에 이탈일이 포함되면 이탈 고객으로 판단해서, 기준월을 바꿔가며 이탈률(이탈 고객 수 ÷ 월초 활성 고객 수)을 계산하는 게 목표입니다.

한 번에 완벽한 프롬프트를 쓰는 대신, 짧은 요청에서 시작해 단계적으로 다듬어가며 필요한 Python 코드를 얻는 과정을 이렇게 실습합니다.

|<center>단계</center>|<center>실습 내용</center>|<center>프롬프트</center>|
|---|---|---|
| 1단계 | 간단한 지시로 시작 | 첨부한 데이터로 월별 고객 이탈률을 확인하는 Python 코드를 작성해줘. (customer_churn.csv 파일을 생성형 AI에게 첨부합니다.) |
| 2단계 | 출력 형식 추가 | 코드는 PEP8 스타일로 작성하고, 코드 위에 자세한 주석을 추가해줘. 답변은 Jupyter Notebook 셀 단위로, 마크다운 형식으로 작성해줘. |
| 3단계 | 배경·분석 범위 추가 | 최근 3개월간 이탈률이 크게 늘었어. 연령대와 가입 채널별 이탈률을 계산하는 교차분석 코드를 작성해줘. 출력 형식을 준수해야 해. |
| 4단계 | 제약 조건 추가 | 이탈률이 가장 높은 집단의 특징을 확인하는 코드를 작성해줘. 이전 대화와 중복되는 코드는 제외하고, 출력 형식을 준수해야 해. |

보이시나요? 1단계는 정말 짧은 지시였는데, 단계가 진행될수록 출력 형식, 배경, 제약 조건이 하나씩 쌓여갑니다. 이게 바로 단계별 요청의 실제 모습입니다.

## 매번 같은 말 반복하기 귀찮으시죠 — 시스템 프롬프트

그런데 위 실습을 보면 "PEP8 스타일로", "Jupyter Notebook 셀 단위로", "출력 형식을 준수해야 해" 같은 말을 매번 반복해서 입력하고 있습니다. 번거롭죠. 이럴 때 쓰는 게 **시스템 프롬프트**입니다.

시스템 프롬프트는 생성형 AI에게 매번 반복해서 말할 내용을 미리 적어두는 설정입니다. 매번 새로 입력해야 하는 건 분석 목적, 데이터 설명, 이번 작업 내용 정도로 줄어들고, 출력 형식·코딩 스타일·제약 조건 등은 시스템 프롬프트에 고정할 수 있습니다. 이걸 쓰면 새 대화를 열어도 같은 스타일의 답변을 얻을 수 있습니다.

## ChatGPT의 맞춤형 GPT

ChatGPT에서는 이 시스템 프롬프트 개념을 '맞춤형 GPT'라는 기능으로 제공합니다. 같은 역할, 같은 출력 형식, 같은 코딩 스타일을 매번 입력하지 않아도 되는 기능인데, 데이터 분석 실습처럼 반복 구조가 있는 작업에서 특히 유용합니다. (참고로 Gemini의 'Gem', Claude의 'Project', Perplexity의 'Space'도 비슷한 목적으로 쓸 수 있는 기능입니다.)

저는 이번 강의를 위해 맞춤형 GPT를 두 가지 작업으로 구분해서 만들어뒀습니다.

|<center>구분</center>|<center>상세 내용</center>|
|---|---|
| HelloDataScience \| Data Analysis Planner | 데이터 파일을 첨부하면 참고 자료를 바탕으로 도메인별 데이터 분석 프로세스를 반영해, 분석 방향을 자연어 프롬프트로 제시합니다. '무엇을, 어떻게 분석할지'를 잡아주는 역할입니다. [바로가기](https://hds.ai.kr/gpt-data-analysis-planner) |
| HelloDataScience \| Python Code Assistant | 자연어 프롬프트를 입력받아, Jupyter Notebook 셀 단위, 마크다운 형식으로 코드를 작성합니다. 출력 형식을 지침에 고정했기 때문에, 대화창에 출력 형식을 매번 추가하지 않아도 됩니다. [바로가기](https://hds.ai.kr/gpt-python-code-assistant) |

역할을 이렇게 두 개로 나누면, 생성형 AI를 더욱 안정적으로 사용할 수 있습니다. 다음 8회차와 9회차에서 이 두 GPT를 실제로 사용해서, 데이터를 첨부하고 결과를 얻는 전체 과정을 함께 해보겠습니다.
